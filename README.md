i’m tired of compromising the experience in my A320 simulator setup, so I’ve decided to build a DIY home cockpit! My first goal is to make the cockpit as modular as possible (e.g., if I want to simulate an A320, I’ll install A320 peripherals; if I change my mind and want to fly a B737, I’ll swap in 737 peripherals). My second goal is to make it as realistic as the real thing—both in terms of feel (the trickiest part, since I’m not a pilot yet and can’t experience the actual sensations) and dimensions (which I’ll ask Gemini about, as they are hard to find). For this specific project, I’m building the A320 FCU—the autopilot panel—and will complete the rest of the home cockpit through future projects
